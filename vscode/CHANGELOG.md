# Change Log

All notable changes to the "rl" extension will be documented in this file.

## [v0.5.0]

- language server support through `ratslang-lsp`: diagnostics, completion, hover, go to definition, document symbols and code actions
- highlighting for angle, velocity, acceleration, frequency and mass units
- extension icon

## [v0.3.1]

- adds all length and time SI units
- warn on unused variables

## [v0.2.0]

- adds micro and nano units

## [v0.1.0]

- Initial release
