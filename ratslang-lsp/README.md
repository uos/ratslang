# Ratslang LSP

Language server for Ratslang, using tree-sitter for editor structure and the
Ratslang compiler for syntax, resolved values, units, and comment constraints.

Installation, editor configuration, schemas, and language-server behavior are
documented in the [Ratslang documentation](https://stelzo.codeberg.page/ratslang/editors/):

* [Install the server](https://stelzo.codeberg.page/ratslang/editors/#install-the-server)
* [Helix](https://stelzo.codeberg.page/ratslang/editors/helix/)
* [Neovim](https://stelzo.codeberg.page/ratslang/editors/neovim/)
* [VS Code](https://stelzo.codeberg.page/ratslang/editors/vscode/)
* [Defaults and constraints](https://stelzo.codeberg.page/ratslang/schemas/)
