# Ratslang LSP

Language server for Ratslang, using tree-sitter for editor structure and the
Ratslang compiler for syntax, resolved values, units, and comment constraints.

Installation, editor configuration, schemas, and language-server behavior are
documented in the [Ratslang documentation](https://ratslang.steado.tech/docs/editors/):

* [Install the server](https://ratslang.steado.tech/docs/editors/#install-the-server)
* [Helix](https://ratslang.steado.tech/docs/editors/helix/)
* [Neovim](https://ratslang.steado.tech/docs/editors/neovim/)
* [VS Code](https://ratslang.steado.tech/docs/editors/vscode/)
* [Defaults and constraints](https://ratslang.steado.tech/docs/schemas/)
